# Product Roadmap

## Phase 0 — Planning
Deliver documentation, threat model, data model, API contract, and evaluation plan.

## Phase 1 — File upload prototype
- Accounts
- PDF, DOCX, TXT, Markdown uploads
- Indexing
- Hybrid search
- Cited answers

Exit: 20 testers can upload files and obtain reliable cited answers.

## Phase 2 — Google connectors
- Google OAuth
- Gmail
- Drive
- Incremental sync
- Disconnect and deletion

Exit: search across Gmail and Drive with stable incremental sync.

## Phase 3 — GitHub
- GitHub App
- Repository selection
- Code-aware indexing
- Issues and pull requests
- Webhooks

Exit: reliable repository and engineering knowledge search.

## Phase 4 — Desktop
- macOS and Windows builds
- Folder picker
- File watcher
- Offline queue
- Signed releases

Exit: local files searchable with safe folder controls.

## Phase 5 — Public beta
- Billing
- quotas
- onboarding
- monitoring
- support tools
- privacy documents
- production hardening

## Phase 6 — Team product
- shared workspaces
- RBAC
- organization connectors
- admin console
- SSO
- audit export
